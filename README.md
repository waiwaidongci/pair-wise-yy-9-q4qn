# 玻璃板回收与二次涂布准入台

由「古法蓝晒底片整理室」扩展而来：旧底片交付后验收玻璃板，准入后才能二次涂布。

## 业务规则

1. **交付后验收登记**：旧底片须为「已交付」，登记划痕、乳剂残留、清洗人三项；任一不达标即转「待复洗」，只能复洗后重新登记，**不能占用涂布槽**。
2. **两人两次洁净确认**：三项达标转「待复认」，由清洗人之外的另一人连续两次确认表面洁净，第二次距第一次满 **4 小时**，两次确认人不得相同。
3. **进入涂布**：两次确认完成转「待涂布」并进入待涂布队列，方可占用涂布槽（同槽不可重复占用）。
4. **失效重算**：玻璃板档案更正，或来源旧底片状态回退，当前回用结论立即失效——版本号 +1，按最新档案重算（不达标回待复洗，达标回待复认并需重新两次确认）；已涂布的板不撤销涂布，仅留档。
5. **旧记录留档**：复洗、更正、回退前的验收与确认记录全部归档，不删除；履历按版本展示。
6. **重复/并发沿用首次结果**：相同幂等键的并发或重复提交共用首次执行结果，不产生重复登记。

## 代码结构（三个业务文件）

| 文件 | 职责 |
| --- | --- |
| `rules.js` | 准入规则：缺陷判定、双确认与四小时间隔、状态机、失效重算（纯函数） |
| `records.js` | 记录存取：验收/复洗/确认/涂布/更正/回退、留档、幂等与并发合并 |
| `page.js` | 页面：底片/玻璃板列表、待涂布队列、玻璃板履历三视图，同一份数据刷新后一致 |
| `server.js` | 仅 HTTP 路由 |

## 运行

```bash
npm start
```

访问 `http://localhost:3040`。数据保存在 `data/cyanotype-negative-room.json`。
